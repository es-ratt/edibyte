# EdiByte API Contract

Base URL: `VITE_API_BASE_URL` (local: `http://localhost:8000`). All bodies are JSON unless noted.
Interactive docs are generated by FastAPI at `/docs` when the backend is running.

**Rule:** calories and nutrients in every response come from the Food table via the
deterministic rules engine. The LLM only extracts food names/amounts and writes coach prose.

Common types:

| Type | Values |
|---|---|
| `lang` | `"bn"` · `"en"` · `"banglish"` |
| `mode` | `"ai"` (LLM configured and reachable) · `"offline"` (rule-based) |
| `unit` | `g` `kg` `ml` `l` `tbsp` `tsp` `plate` `bati` `cup` `glass` `piece` `slice` `handful` `serving` |

Nutrients on `Food` are **per 100 g edible portion**. `serving_grams` is one typical serving.
Container/count units (`plate`, `bati`, `cup`, `glass`, `piece`, `slice`, `handful`, `serving`)
mean *one standard serving of that food*; `g/kg/ml/l/tbsp/tsp` are fixed weights.

## `GET /health`
```json
{ "status": "ok", "mode": "offline", "provider": "none", "photo_enabled": false, "foods": 48 }
```

## `POST /meal/parse`
Request
```json
{ "text": "ek plate bhat ar dal, pizza", "lang": "banglish" }
```
`text`: 1–2000 chars (normalised and cut to 500). Response
```json
{
  "items": [
    {
      "raw_name": "bhat",
      "food": { "id": "bhat", "name_bn": "ভাত", "name_en": "Cooked white rice", "name_bl": "Bhat",
                "category": "grain", "serving_desc_bn": "১ প্লেট", "serving_desc_en": "1 plate",
                "serving_grams": 250, "verified": false },
      "quantity": 1, "unit": "plate", "grams": 250, "assumed": false, "confidence": 1.0
    }
  ],
  "unmatched": [
    { "raw_name": "pizza", "quantity": null, "unit": null, "suggestions": [ /* FoodBrief x3 */ ] }
  ],
  "normalized_text": "ek plate bhat ar dal, pizza",
  "lang": "banglish",
  "mode": "offline",
  "warnings": []
}
```
`assumed: true` means no quantity was given and one default serving was used.
Possible `warnings`: `ai_unavailable_used_offline_parser`, `no_food_found`.

## `POST /meal/parse-image` (feature flag)
`multipart/form-data` with `image` (JPEG/PNG/WebP, ≤ 4 MB) and `lang`. Returns the same shape as
`/meal/parse`. `404` when `ENABLE_PHOTO=false` (default), `503` when no LLM is configured.

## `POST /meal/report`
Request
```json
{
  "items": [ { "food_id": "bhat", "quantity": 1, "unit": "plate" }, { "food_id": "dal", "quantity": null, "unit": null } ],
  "profile": { "goal": "maintain", "sex": "female", "age": 21, "height_cm": 157, "weight_kg": 50,
               "activity": "light", "diet": "any", "daily_budget_bdt": 150 },
  "lang": "bn",
  "meal_type": "lunch",
  "session_id": "anonymous-browser-id-or-null"
}
```
`profile` limits: age 18–80, height 120–220 cm, weight 30–200 kg. `goal`: `lose|maintain|gain_muscle`;
`sex`: `male|female|unspecified`; `activity`: `sedentary|light|moderate|active|very_active`;
`diet`: `any|vegetarian|no_beef`. If `session_id` is set, a meal log (food ids + grams only) is stored.

Response (abridged)
```json
{
  "items": [ { "food": { /* FoodBrief */ }, "quantity": 1, "unit": "plate", "grams": 250, "assumed": false,
               "nutrients": { "kcal": 325, "protein_g": 6.8, "carbs_g": 70, "fat_g": 0.8, "fiber_g": 1 },
               "source": "UNVERIFIED SAMPLE - team must replace with sourced data", "fiber_known": true } ],
  "totals": { "kcal": 430, "protein_g": 13.6, "carbs_g": 86.5, "fat_g": 2.6, "fiber_g": 4 },
  "targets": { "kcal": 1671, "protein_g": 50, "carbs_g": 251, "fat_g": 52, "fiber_g": 25,
               "bmr": 1215, "tdee": 1671, "floor_applied": false, "floor_kcal": 1200 },
  "percent_of_target": { "kcal": 26, "protein_g": 27, "carbs_g": 34, "fat_g": 5, "fiber_g": 16 },
  "tips": [ { "id": "balance_rice", "text": "…", "rule": "high_carb", "verified": false, "source": "…" } ],
  "swaps": [],
  "swaps_note": "no_price_data",
  "has_unverified": true,
  "profile_used": { /* Profile */ },
  "lang": "bn",
  "disclaimer": "এটি সাধারণ পুষ্টি তথ্য, চিকিৎসা পরামর্শ নয়।"
}
```
`swaps` are returned **only** when foods have a `price_bdt_estimate` with a `price_source`.
`swaps_note`: `no_price_data` · `no_cheaper_option` · `null`. Unknown `food_id` → `422`.

## `POST /coach`
Request
```json
{ "question": "dim e koto protein?", "lang": "banglish", "profile": { /* optional Profile */ },
  "history": [ { "role": "user", "content": "…" }, { "role": "assistant", "content": "…" } ] }
```
Response
```json
{
  "answer": "… \n\nEta general nutrition information, medical advice na.",
  "sources": [ { "type": "food", "id": "dim_sheddho", "title": "সেদ্ধ ডিম / Boiled egg",
                 "source": "UNVERIFIED SAMPLE - team must replace with sourced data", "verified": false } ],
  "lang": "banglish",
  "mode": "offline",
  "guardrail": null
}
```
`guardrail`: `null` · `medical` · `pregnancy` · `eating_disorder` (then `sources` is empty and the
answer is a kind redirect to a doctor/dietitian). The disclaimer is always appended server-side.

## `GET /foods?query=&limit=20`
List or search foods (prefix + fuzzy across Bangla, English and aliases). Returns full `Food` rows.

## `GET /profiles/demo`
Two fictional demo profiles: `student_budget`, `muscle_gain`.

## `POST /profiles/targets`
Body: `Profile`. Returns `Targets` (same as in the report).

## `GET /data/status`
```json
{ "foods_total": 48, "foods_verified": 0, "foods_with_price": 0, "tips_total": 15, "tips_verified": 0,
  "sources": [ { "source": "UNVERIFIED SAMPLE - team must replace with sourced data", "rows": 48 } ],
  "nutrient_basis": "per 100 g edible portion" }
```

## `GET /eval/results`
`{ "status": "not_run", "message": "Not run yet" }` until `python -m eval.run` has been run;
afterwards `{ "status": "ok", "timestamp", "test_set": "team-made", "mode", "overall", "by_lang", "failures", … }`.

## `DELETE /session/data`
Header `X-Session-Id: <anonymous id>`. Deletes stored meal logs for that id. Returns `{ "deleted": n }`.

## Errors
`422` validation error (FastAPI format) · `429` `{ "detail": "...", "code": "rate_limited" }` with
`Retry-After: 60` · `404/413/415/503` on the photo endpoint as described above.
